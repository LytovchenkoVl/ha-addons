# ДТЕК графіки — Telegram-бот

Бот бере графік відключень прямо з сайту ДТЕК (тих самих даних, що бачить сторінка «Відключення»),
перевіряє його кожні кілька хвилин і пише в Telegram, щойно графік **вашої черги** змінився
або з'явився графік на завтра. У повідомленні — графік на сьогодні, чи є світло зараз,
коли наступна зміна, і графік на завтра (або «графіка ще немає»).

Регіони: Київ (ДТЕК КЕМ), Київська область (ДТЕК КРЕМ), Дніпропетровська (ДТЕК ДнЕМ), Одеська (ДТЕК ОЕМ).

## 1. Створіть бота в Telegram

1. Відкрийте [@BotFather](https://t.me/BotFather), надішліть `/newbot`.
2. Придумайте назву та ім'я, що закінчується на `bot`.
3. Скопіюйте токен вигляду `1234567890:AA...` — він знадобиться в налаштуваннях.

## 2. Скопіюйте add-on на сервер Home Assistant

Найпростіше через add-on **Samba share** (Налаштування → Доповнення → Магазин доповнень → Samba share → Встановити,
у вкладці «Конфігурація» задайте логін і пароль, запустіть).

У Windows відкрийте в Провіднику `\\homeassistant.local\addons` (або `\\<IP сервера>\addons`)
і скопіюйте туди всю папку `dtek_power_bot` (у ній мають лежати `config.yaml`, `Dockerfile`, папка `app`).

## 3. Встановіть

1. Налаштування → Доповнення → **Магазин доповнень** → меню ⋮ праворуч угорі → **Перевірити оновлення**.
2. Унизу з'явиться розділ **Local add-ons** → «ДТЕК графіки — Telegram бот» → **Встановити**.
   Перше встановлення триває 5–20 хвилин: сервер завантажує Python і браузер Chromium (~600 МБ).
3. Вкладка **Конфігурація**:
   - `telegram_token` — токен від BotFather;
   - `poll_minutes` — як часто перевіряти сайт (типово 2 хв);
   - **Доступ для всіх** (`allow_all`) — увімкнено: ботом може користуватися будь-хто, хто його знайде.
     Вимкнено: лише люди зі списку нижче;
   - **Дозволені користувачі** (`allowed_users`) — по одному в рядку: числовий Telegram ID (`123456789`)
     або ім'я користувача (`@mama_k`). ID надійніший, бо @username людина може змінити;
   - **Відповідь для сторонніх** (`deny_message`) — що бот напише людині без доступу.
   - **Адміністратори** (`admin_users`) — ID або @username тих, кому доступна команда `/stats`.
     Адміністратори завжди мають доступ до бота, навіть якщо їх немає серед дозволених.

   Як дізнатися чийсь ID: хай людина напише боту `/start`, поки доступ обмежено. Бот відповість їй
   її ID, а у вкладці **Журнал** з'явиться рядок `Відмовлено в доступі: Ім'я (@username), ID ...`.
   Додайте цей ID у список, натисніть «Зберегти» і перезапустіть add-on.
   Якщо людину прибрати зі списку, її налаштування збережуться, але сповіщення приходити перестануть.
4. Вкладка **Інформація**: увімкніть «Запускати при завантаженні» і «Watchdog», натисніть **Запустити**.
5. Вкладка **Журнал**: має з'явитися `Бот запущено`.

## Зміна налаштувань і токена

Усе змінюється в тій самій вкладці **Конфігурація**: токен, частота перевірки, доступ, текст відмови.
Після змін натисніть «Зберегти» і перезапустіть add-on (Home Assistant сам запропонує це зробити).
Поле токена приховане зірочками, показати його можна іконкою ока.

- **Новий токен того самого бота** (наприклад, після `/revoke` у BotFather, якщо токен потрапив до сторонніх):
  все працює далі, нічого робити не потрібно.
- **Токен зовсім іншого бота**: Telegram не дозволяє новому боту писати людям першим. Збережені адреси
  нікуди не зникнуть, але сповіщення стануть на паузу, доки кожна людина не відкриє нового бота і не
  натисне «Почати» (`/start`). Після цього бот покаже її стару адресу і знову надсилатиме графіки.

## 4. Користування

- `/start` — обрати регіон, потім адресу (населений пункт → вулиця → будинок) або одразу чергу.
  Якщо будинок у двох чергах, бот стежить за обома.
- `/now` — графік зараз (кнопка «🔄 Оновити» під кожним повідомленням робить те саме).
- `/stop` — вимкнути сповіщення.
- `/help` — що вміє бот.
- `/stats` — статистика, лише для адміністраторів: скільки людей запускали бота й заходили сьогодні/за тиждень, підписки за регіонами, скільки сповіщень надіслано, чи вдається перевіряти сайт ДТЕК, хто просив доступ (з ID, щоб додати в список). Якщо адміністратора вказано числовим ID, `/stats` з'явиться в його меню команд.

Для адреси бот також показує аварійні чи планові роботи на будинку, якщо сайт їх вказує —
їх немає в графіку черг.

## Важливо знати

- Час «Дата оновлення інформації», який сайт показує біля адреси, оновлюється постійно — це не
  означає, що змінився графік. Бот порівнює саме години відключень вашої черги, тому пише лише про реальні зміни.
- Опівночі бот нічого не надсилає: вчорашній «завтра» просто стає «сьогодні».

## Якщо не працює

- У журналі `Timeout ... waiting for function` або `HTTP 403` — сайт ДТЕК тимчасово не пропустив браузер
  (антибот-захист). Бот сам повторює спробу на наступній перевірці; якщо помилка не зникає годинами — перезапустіть add-on.
- `Не вказано telegram_token` — заповніть токен у конфігурації і перезапустіть.
- Після зміни файлів у папці `addons/dtek_power_bot` збільште `version` у `config.yaml`,
  натисніть «Перевірити оновлення» і «Оновити» (або «Перебудувати»).

Підписки зберігаються у `/data/subscriptions.json` всередині add-on і переживають перезапуски та оновлення.
