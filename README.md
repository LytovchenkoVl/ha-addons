# Доповнення Home Assistant: графіки відключень ДТЕК

Telegram-бот, який бере графік відключень прямо з сайту ДТЕК і пише, щойно змінюється графік вашої черги
або з'являється графік на завтра.

## Встановлення

1. Home Assistant → Налаштування → Доповнення → Магазин доповнень → ⋮ → **Репозиторії**.
2. Вставте адресу цього репозиторію і натисніть «Додати».
3. Знайдіть «ДТЕК графіки — Telegram бот», встановіть, вкажіть токен від @BotFather у вкладці «Конфігурація», запустіть.
